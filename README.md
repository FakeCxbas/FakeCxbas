## Automatización con Python

**MxCorreo** es una aplicación portable para Windows con importación de Excel y CSV, detección de duplicados, revisión de sintaxis y DNS/MX e informes. También incorpora simulación de envíos, SMTP cifrado y registro en SQLite.

La utilicé para procesar **36.040 registros de correo** de una empresa en el primer lote, identificando **24.604 direcciones únicas**. La revisión DNS clasifica dominios; no confirma la existencia de cada buzón. El proyecto cuenta con 78 pruebas automatizadas. Los datos y las listas de la empresa no son públicos.
